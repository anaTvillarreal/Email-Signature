# Wayfinder Email Signature Builder

A one-page tool that helps Wayfinder employees set up their Gmail signature. Everything runs in the browser, so no photos or details are uploaded anywhere.

## Publish It on GitHub Pages

1. Sign in to github.com, or create a free account.
2. Click **+** → **New repository**. Name it `email-signature`, set it to **Public**, and click **Create repository**.
3. Click **uploading an existing file**. Drag in `index.html`, `README.md`, and the whole `assets` folder. Click **Commit changes**.
4. Go to **Settings** → **Pages**. Under *Build and deployment*, set *Source* to **Deploy from a branch**, set *Branch* to **main** and **/ (root)**, then click **Save**.
5. Wait 1–2 minutes, then refresh. Your link appears at the top: `https://YOUR-USERNAME.github.io/email-signature/`

## Update It Later

Open the repository, click `index.html`, then click the pencil icon to edit it, or upload a new version with **Add file** → **Upload files**. The live page updates in a minute or two.

## What's in Here

- `index.html`: the page
- `assets/wayfinder-logo.png`: the logo used in signatures (must stay at this path)
- `assets/photo-placeholder.png`: the placeholder photo people swap out in Gmail (must stay at this path)
